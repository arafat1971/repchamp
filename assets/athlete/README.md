# Reps widget athlete renders

Put realistic renders here and rebuild; the Reps widget uses them instead of
the drawn athlete. A folder with fewer than two PNGs falls back to the drawing.

- `male/` and `female/` — one push-up each, **side view, facing left**
- **4–6 frames**, arms locked out → chest down, named so they sort: `1.png`, `2.png`, …
  (the widget plays them down and back up)
- **Transparent PNG**, same canvas and same framing in every frame
  (camera and floor line don't move — only the body)
- About **600 × 400 px** (landscape, ~3:2); keep files under ~150 KB each
