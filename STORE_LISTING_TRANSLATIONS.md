# Play Store listing: translations

Translated versions of the English listing in `STORE_LISTING.md` (2026-10-28).
Every claim matches the English copy, which is checked against build 38.

**Where:** Play Console → Grow users → Store presence → Store listings →
Default store listing → **Manage translations → Add your own translations**.
Pick the language, then paste the three fields. Leave the graphics as they are
unless you have translated screenshots.

**Before publishing:** have a native speaker read at least the name and short
description of each. These are written by hand, not machine-translated, but a
native read catches tone that a fluent non-native misses.

The app itself is English-only, so each description ends with a line saying
so, and in-app labels ("Walk now", "Settings", Strength/Yoga/Mind/Together)
stay in English so they match what people see after installing. That keeps refund requests and 1-star "not in my language" reviews down.

The name is chosen per market for what people there actually search: "pasos"
and "flexiones" in Spanish, "passos" and "flexões" in Portuguese, "Schrittzähler"
in German, "langkah" in Indonesian. Hindi users often search in English, so
the Hindi name keeps "rep" and "step" as Hindi loanwords.

Limits: name 30, short description 80, full description 4000 characters.
Lengths are listed under each block, counted as Play counts them.
